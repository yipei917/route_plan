# V3版本

## 修改内容

### 地图

1. 添加上下巷道类型
2. 添加接驳口类型
3. 添加主干道状态

### 调度器——重构

1. 系统初始化（初始化地图、任务、车辆位置、货物位置等）
2. 为小车分配任务
3. 检查车辆状态并处理状态转换
4. 分析小车路径，将路径分段
5. 为小车分配、锁定执行路径
6. 路径冲突策略
7. 小车避让策略
8. 模拟系统运行

### 模拟器——新增

1. 模拟小车行动

### 车辆

1. 重构原来路径为规划路径和执行路径
2. 新增目标坐标和避让坐标
3. 重构小车状态为：空闲、取货、送货、避让、等待
4. 修改状态转换逻辑

### 约束器——重构

1. 管理车辆的路径冲突和方向冲突
2. 为路径添加、检测、删除约束（锁定、解锁）
3. 为路径添加、删除方向限制

### 简易前端

1. 前端可视化自动执行任务
